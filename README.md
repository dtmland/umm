# umm

Command-line media metadata tool built on [libumm](https://github.com/dtmland/libumm).
Canonical IPTC / EXIF vocabulary, not backend tag names. The CLI adds no
metadata logic of its own.

This repository is being built from the founding [concept](docs/concept.md)
in session-sized packages. See [docs/README.md](docs/README.md) and
[docs/implementation/00-overview.md](docs/implementation/00-overview.md).

The full README, getting started guide, and examples land in
[session 15](docs/implementation/15-documentation.md).
